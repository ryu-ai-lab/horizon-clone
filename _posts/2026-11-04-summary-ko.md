## [Postman Under Fire for Silent AI Plugin Installation and Data Sharing](https://github.com/postmanlabs/postman-app-support/issues/14370) ⭐️ 9.0/10

Postman is facing significant backlash for silently installing AI plugins and attempting to share sensitive API data, including secrets, without explicit user consent, leading to widespread user concern and organizational decertification. This incident raises critical privacy and security concerns for a widely used developer tool, potentially impacting compliance requirements like HIPAA and eroding user trust, which is prompting a mass migration to alternative tools. Postman reportedly logs detailed information on every API request, including query parameters and actual secret content from templating syntax, and disabling the network traffic to this logging endpoint causes the entire application to malfunction.

hackernews · sidgarimella · 11월3일 17:22 · [커뮤니티 토론](https://news.ycombinator.com/item?id=50354960)

**배경 지식**: Postman is a popular API development tool used by developers to design, test, and document APIs. APIs (Application Programming Interfaces) allow different software systems to communicate, and often involve sensitive data or "secrets" like API keys or authentication tokens. HIPAA is a US law that sets standards for protecting sensitive patient health information.

**커뮤니티 토론**: The community expresses disappointment over Postman's transformation from a simple tool into a bloated, data-collecting enterprise, with many users citing performance issues and security concerns, especially regarding HIPAA compliance. Many users have already migrated to alternative tools like Bruno, highlighting a significant loss of trust and a shift in the developer tool landscape.
