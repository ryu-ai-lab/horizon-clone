## [LLM Tool Fixes Logging Issue Due to SQLite JSON Behavior Change](https://simonwillison.net/2026/Nov/16/llm/) ⭐️ 5.0/10

The `llm` tool released version 0.37.3 to address a bug in its logging functionality, which was broken by a change in SQLite 3.54.1's `json_object` behavior when processing `json_array` subqueries. This update ensures compatibility with the latest SQLite version shipped by Homebrew. This bug fix is critical for users of the `llm` tool, ensuring its data logging capabilities remain operational following an update to its underlying database dependency, SQLite. It highlights the importance of careful dependency management and the potential for subtle changes in library behavior to cause significant application issues. SQLite 3.54.1 changed the output of `json_object` when its value argument is a `SELECT json_array(...)` subquery, treating the subquery's result as SQL text rather than JSON, which was confirmed as the correct behavior by D. Richard Hipp. The fix for `llm` involves explicitly wrapping the subquery with the `json()` function to ensure it's interpreted as JSON.

rss · Simon Willison · 11월16일 23:57

**배경 지식**: `llm` is a command-line tool developed by Simon Willison, often used for interacting with large language models and storing their outputs. SQLite is a widely used, serverless, self-contained, and transactional SQL database engine, popular for embedded applications and local data storage. The `json_object` and `json_array` functions in SQLite allow developers to construct and manipulate JSON data directly within SQL queries.
