## [uv 0.12.18 Fixes Windows Path Traversal, Adds JSON Output and Dry-Run](https://github.com/astral-sh/uv/releases/tag/0.12.18) ⭐️ 7.0/10

The `uv` release 0.12.18, dated 2026-09-22, addresses a critical Windows-specific path traversal vulnerability (GHSA-2cv4-cqwr-gwf7) during wheel installation. This update also introduces significant enhancements such as `--output-format json` and `--check` (dry-run) functionality for `uv pip install` and `uv pip sync` commands. This release is crucial for enhancing the security posture of `uv` users on Windows by patching a serious path traversal vulnerability that could lead to unauthorized file access. The new JSON output and dry-run capabilities significantly improve automation, scripting, and planning for Python package management workflows, making `uv` a more robust and developer-friendly tool. The security fix specifically targets archive entries that normalize to absolute Windows paths, preventing malicious path traversal during wheel installation. New `--check` and `--output-format json` options are available for `uv pip install` and `uv pip sync`, allowing users to preview changes and integrate `uv`'s output into automated systems more easily. Additionally, the release improves the identification of build failures from `get_requires_for_build_*` hooks and speeds up editable wheel creation.

github · astral-releases-bot[bot] · 9월22일 23:00

**배경 지식**: A path traversal vulnerability, also known as directory traversal, allows attackers to access files and directories stored outside the intended root directory by manipulating file paths, often using sequences like `../`. Python's "wheel" format (`.whl`) is a standard binary package format that is essentially a ZIP archive containing pre-built code and metadata, designed for faster and more reliable installation without requiring compilation steps.
