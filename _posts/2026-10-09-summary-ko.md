## [Whistle: A 16.9 MB Speech-to-Text Model for Resource-Constrained Devices](https://cactuscompute.com/blog/whistle) ⭐️ 8.0/10

Cactus Compute has released Whistle, a new open speech-to-text model weighing only 16.9 MB, designed to run efficiently on local CPUs in resource-constrained environments and supporting seven languages. Released on October 2nd, it leverages the same CPU engine as Needle, enabling on-device processing without GPU or external dependencies. This model's extremely compact size is significant for expanding advanced speech recognition capabilities to edge computing, wearables, and smart home devices, enabling privacy-preserving local processing. It reduces reliance on cloud infrastructure, making AI-driven applications faster, more reliable, and more secure in resource-constrained environments. Whistle is a standalone 16.9 MB file that operates entirely on a CPU without any dependencies or GPU requirements, achieving its first token output in 11 milliseconds. However, community feedback indicates potential accuracy trade-offs compared to larger models and notes the absence of a crucial streaming output feature for real-time applications.

This approach is becoming increasingly crucial for connected devices like IoT sensors and smart cameras, facilitating faster, more reliable, and more secure AI-driven applications. Speech-to-Text (STT), also known as Automatic Speech Recognition (ASR), is a technology that converts spoken language into written text.
